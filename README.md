# Pick Pack Notes

A browser-based melody collecting rhythm game that automatically generates
stages just by loading music files (MP3/WAV/OGG, etc.). Simply move your
character left and right to align with the falling notes to collect them
automatically without tapping. You can also play MIDI files directly and change
the sound source using SoundFonts (SF2/SF3).

## Build

```
bash build.sh
```
